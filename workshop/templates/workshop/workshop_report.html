Méthode et définitions

  • Source : base de données des ateliers Médi@'pass.
  • Période : année {{ selected_year }}.
  • Périmètre : {% if synthese.perimetre %}{{ synthese.perimetre }}{% else %}tous les ateliers de l’année{% endif %}.
  • Inscrits : nombre de personnes inscrites renseigné pour chaque atelier. Présents : nombre de participants effectivement présents.
  • Taux de présence : présents divisés par inscrits. Il n’est pas calculé lorsque le nombre d’inscrits est nul.
  • Regroupement des intitulés : casse, accents, pluriels et mots de format (Atelier, Initiation, Découverte, Soirée, Tournoi, etc.) sont neutralisés. Les sujets différents restent séparés.
  • Les données sont agrégées : le rapport ne contient aucun nominatif.
